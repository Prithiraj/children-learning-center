# Demo imagery — production blocker

Everything in this directory is an original, development-only illustration created for layout and screenshot validation. It does **not** depict I Love Children Learning Center, its staff, its students, or its premises.

Before commercial launch:

1. Replace `hero-demo.svg` and every `gallery-*.svg` image with owner-controlled business photography.
2. Confirm the business owns or licenses each image for website and promotional use.
3. Obtain appropriate parent/guardian releases for identifiable minors and photographer permission where needed.
4. Keep `photo-fallback.svg` as a neutral technical fallback if desired, but it must never be presented as business photography.

No Google Maps, Winnie, competitor, review-upload, or other scraped third-party photography is included in this repository.
